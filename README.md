# 🐾 Pet Booking App

Pet Booking App is a React Native mobile application that allows pet owners to manage different types of pet service bookings in one place.

Users can register and log in, create bookings for veterinary services, grooming services, and pet hotel stays, and manage their existing appointments through the mobile application.

## 🚀 Features

- User registration and login
- Create veterinary bookings
- Create grooming bookings
- Create pet hotel bookings
- View and manage existing appointments
- Separate booking forms for different pet services
- User profile management
- Local data storage using SQLite
- Mobile navigation with custom tab navigation

## 🛠️ Technologies Used

- React Native
- TypeScript
- JavaScript
- SQLite
- Android
- iOS
- npm

## 📁 Project Structure

- `Screens/` – Main application screens such as Login, Register, Home, Profile, and Bookings
- `components/` – Reusable components and booking forms
- `database/` – SQLite database setup
- `images/` – Application images and logo
- `android/` – Android project files
- `ios/` – iOS project files
